# 01 — Основы HTML и CSS
 
## 🎯 Задача
Первое практическое занятие курса: познакомиться со структурой HTML-документа и базовыми возможностями CSS.
 
## 🧩 Что отработано
- Структура HTML-документа: `<!DOCTYPE html>`, `<head>`, `<body>`
- Заголовки `h1`–`h6` и их визуальная иерархия
- Абзацы `<p>`, блочные `<div>` и строчные `<span>` элементы
- Курсив через тег `<i>`
- Атрибут `id` и обращение к нему в CSS через `#myid1`
- Внутренний CSS через тег `<style>`
- Свойства `color`, `background`, `text-align`
 
## 🧪 Технологии
HTML5, CSS3 (внутренние стили)
 
## 📝 Чему научилась
- Поняла разницу между блочными и строчными тегами
- Разобралась, как `id` позволяет стилизовать конкретный элемент
- Впервые применила CSS-свойства для изменения цвета и выравнивания текста
