# 02 — Подключение CSS, классы и работа с изображениями
 
## 🎯 Задача
Отработка подключения внешнего файла стилей, изучение атрибутов `class` и `id`, а также добавление изображений на страницу.
 
## 🧩 Что отработано
- Подключение внешнего CSS-файла через тег `<link>`
- Работа с атрибутом `class` для группировки стилей
- Работа с атрибутом `id` для уникальных элементов
- Использование тега `<img>` для вывода картинки
- Теги `<sup>` (верхний индекс) и `<small>` (мелкий текст)
- Горизонтальная линия `<hr>`
 
## 🧪 Технологии
HTML5, CSS3 (внешние стили)
