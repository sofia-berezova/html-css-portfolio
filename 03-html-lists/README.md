# 03 — Нумерованные и маркированные списки
 
## 🎯 Задача
Изучение различных видов списков в HTML, их вложенности и стилизации через CSS.
 
## 🧩 Что отработано
- Нумерованные списки `<ol>` и маркированные `<ul>`
- Изменение нумерации (атрибуты `reversed` и `value`)
- Создание вложенных списков (список в списке)
- Стилизация маркеров списков через CSS (`list-style-type`: римские цифры, кружки, диски)
- Использование спецсимволов (`&lt;` и `&gt;`)
 
## 🧪 Технологии
HTML5, CSS3
