# 04 — Форматирование текста и стилизация
 
## 🎯 Задача
Изучение возможностей форматирования текста в HTML и CSS, а также стилизация фрагментов кода.
 
## 🧩 Что отработано
- Выделение текста курсивом (`<i>`) и жирным шрифтом (через CSS `font-weight`)
- Использование тега `<pre>` для сохранения пробелов и форматирования кода
- Стилизация текста через CSS: `text-decoration-line`, `text-decoration-style`, `color`, `background-color`
- Работа со спецсимволами (`&lt;` и `&gt;`)
- Группировка стилей для нескольких тегов (через запятую: `h1, h3`)
 
## 🧪 Технологии
HTML5, CSS3
