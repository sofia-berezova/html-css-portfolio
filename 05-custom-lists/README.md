# 05 — Списки определений и кастомные маркеры
 
## 🎯 Задача
Изучение списков определений (`<dl>`) и замена стандартных маркеров списка на собственные изображения.
 
## 🧩 Что отработано
- Создание списков определений с помощью тегов `<dl>`, `<dt>` (термин) и `<dd>` (описание)
- Замена маркеров списка на картинки через CSS-свойство `list-style-image`
- Работа с относительными путями к изображениям
- Вложенные списки и применение разных иконок для разных групп (времена года, платформы)
 
## 🧪 Технологии
HTML5, CSS3
