# 06 — Блочная модель (Box Model)
 
## 🎯 Задача
Изучение основ блочной модели CSS: рамки, отступы (внутренние и внешние) и основы выравнивания элементов.
 
## 🧩 Что отработано
- Свойство `border` (рамки), `border-radius` (скругление углов)
- Внешние отступы `margin` и внутренние отступы `padding`
- Позиционирование элементов с помощью `display: inline-flex` и `flex-direction: column`
- Выравнивание контента по центру (`align-items`, `justify-content`, `text-align`)
 
## 🧪 Технологии
HTML5, CSS3 (Flexbox)
