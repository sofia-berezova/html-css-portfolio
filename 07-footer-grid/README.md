# 07 — Футер сайта и CSS Grid
 
## 🎯 Задача
Создание подвала сайта (footer) с использованием CSS Grid для разметки сетки и эффекта наведения на иконки.
 
## 🧩 Что отработано
- Свойство `display: grid` и `grid-template-columns`
- Эффект черно-белого изображения через `filter: grayscale()` и его снятие при наведении (`:hover`)
- Плавные переходы через `transition`
 
## 🧪 Технологии
HTML5, CSS3 (Grid, Flexbox)
