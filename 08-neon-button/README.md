# 08 — Неоновая кнопка
 
## 🎯 Задача
Создание красивой анимированной кнопки с эффектом неонового свечения.
 
## 🧩 Что отработано
- Свойство `box-shadow` для создания свечения
- Псевдокласс `:hover` для изменения стиля при наведении
- Свойство `transition` для плавности анимации
- Трансформация размера через `transform: scale()`
 
## 🧪 Технологии
HTML5, CSS3 (Анимации)
