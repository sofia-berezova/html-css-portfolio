# 09 — Блочные и строчные теги
 
## 🎯 Задача
Изучение разницы между блочными (`div`) и строчными (`span`) элементами, а также изменение их поведения через CSS.
 
## 🧩 Что отработано
- Разница между `div` (занимает всю ширину) и `span` (занимает ширину текста)
- Свойство `display: block`, `inline` и `inline-block`
- Работа с рамками для наглядности границ элементов
 
## 🧪 Технологии
HTML5, CSS3
