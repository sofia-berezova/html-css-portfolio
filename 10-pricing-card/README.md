# 10 — Карточка тарифа (Pricing Card)
 
## 🎯 Задача
Создание стилизованной карточки с тарифным планом, используя тени, отступы и Flexbox для выравнивания.
 
## 🧩 Что отработано
- Создание теней через `box-shadow`
- Стилизация кнопок и эффект наведения (`:hover`)
- Центрирование карточки на странице через `display: flex` для `body`
- Выравнивание элементов внутри карточки через `flex-direction: column`
 
## 🧪 Технологии
HTML5, CSS3 (Flexbox)
