# 11 — Боковое меню и Таблицы
 
## 🎯 Задача
Создание анимированного бокового меню (Sidebar) и верстка таблиц с объединением ячеек.
 
## 🧩 Что отработано
- Анимация ширины блока через `transition` при наведении (`:hover`)
- Изменение прозрачности текста через `opacity`
- Создание таблиц (`table`, `tr`, `td`, `th`)
- Объединение ячеек по вертикали (`rowspan`) и по горизонтали (`colspan`)
- Объединение границ таблицы через `border-collapse`
 
## 🧪 Технологии
HTML5, CSS3
