# 12 — Поля ввода и формы
 
## 🎯 Задача
Изучение различных типов полей ввода `<input>` и их атрибутов.
 
## 🧩 Что отработано
- Различные типы `<input>`: `text`, `password`, `radio`, `checkbox`, `color`, `date`, `time`, `file`, `range`, `email`
- Атрибуты `placeholder`, `readonly`, `disabled`
- Работа со слайдером (`type="range"`)
- Вставка изображения и изменение его базовых размеров через HTML-атрибуты
 
## 🧪 Технологии
HTML5, CSS3
