# 13 — Фотогалерея и CSS Grid
 
## 🎯 Задача
Создание сетки изображений с помощью CSS Grid и изменение порядка их отображения с помощью свойства `order`.
 
## 🧩 Что отработано
- Создание сетки из 2 колонок (`grid-template-columns: repeat(2, 1fr)`)
- Изменение визуального порядка элементов без изменения HTML-кода (`order`)
- Адаптивные изображения (`width: 100%`)
 
## 🧪 Технологии
HTML5, CSS3 (Grid)
