# 14 — CSS-анимация
 
## 🎯 Задача
Создание анимации с помощью `@keyframes` и свойства `animation`. Летающие овцы на фоне градиентного неба.
 
## 🧩 Что отработано
- Создание кадров анимации через `@keyframes`
- Свойства анимации: `animation-duration`, `timing-function`, `infinite`, `alternate`
- Трансформации: `translateX` (сдвиг по горизонтали) и `scale` (масштабирование)
- Задержка анимации (`animation-delay`)
 
## 🧪 Технологии
HTML5, CSS3 (Анимации)
